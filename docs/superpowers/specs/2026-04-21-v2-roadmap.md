## Part 1 — Shipped in this pass

### Backend security & stability

| Fix | Why it mattered |
|-----|-----------------|
| **Path traversal in SPA fallback closed** (`main.py`) | Encoded dot-segments (`/%2e%2e/...`) could serve ANY file the process can read — including `local.db` and source. realpath + prefix check now enforced. |
| **Async email** (`email.py` + 4 call sites) | The sync Resend SDK stalled the entire event loop — including every in-flight SSE chat stream — for the duration of each email HTTP call. Now `asyncio.to_thread`. |
| **Rate limiting** (slowapi) | login 5/min, register 3/min, forgot-password + resend-verification 3/min;10/hr, chat 20/min, error-report 30/min, story-like 20/min. Dockerfile now passes `--proxy-headers --forwarded-allow-ips` so per-IP buckets work behind Railway's proxy. |
| **Session revocation** (`users.token_version` + `tv` JWT claim) | Password reset now invalidates every outstanding access AND refresh token. Previously a stolen session survived a reset for up to 30 days. |
| **Chat SSE no longer pins a DB connection** (`routes/chat.py`) | The old `Depends(get_db)` held a pool connection for the whole stream (up to 120s). With pool_size 5 + overflow 10, **15 concurrent chats took down the entire app**. Key resolution now uses a short-lived session closed before streaming. |
| **Public share spoiler leak closed** (`routes/stories.py`) | `/api/share/{slug}` returned the raw `world_bible` (DM secrets, plot) and full `game_data` (hidden trackers). Now `extract_world_briefing()` + a presentation-safe key whitelist. |
| **Image-gen key mixup fixed** (`routes/images.py`) | The stored OPENROUTER key was preferred over the request-body key and sent to xAI — leaking the credential to a third party AND guaranteeing a 401. Body key now wins. |
| **Input validation** | Register: password ≥8, username 3-100 chars + charset. Campaign name 1-255. Error reports size-capped (unauthenticated flood vector — could previously fill the DB disk). |
| **Error detail hygiene** | Stripe/recap/test exceptions no longer interpolate raw exception text into client-visible `detail`. |
| **Security headers** | nosniff, X-Frame-Options DENY, Referrer-Policy, HSTS (prod). |
| **Hot-path indexes** | `campaigns(owner_id,status,updated_at)`, `stories(is_public,created_at)`, `notifications(user_id,read)`, `error_logs(resolution_status)`. |

### Frontend bugs (all three suspects confirmed and fixed)

| Bug | Root cause → fix |
|-----|------------------|
| **Cloud sync dropped renames + could wipe progress** | (a) read `campaign.worldName` — a field that doesn't exist (it's `.name`); (b) unmount flush captured the FIRST-render closure and could PUT the initial empty state over real progress; (c) the trailing 30s debounce reset on every change, so during active play it **never fired**. Now: correct field, ref-based flush, dirty-flag + fixed 30s interval. |
| **Chat history duplicated on re-hydrate** | `loadFromLocalStorage` APPENDED messages and the load effect re-ran on every authFetch identity change. Now: replace-not-append + refs guard both branches. |
| **SSE stream could write into the wrong message** | `UPDATE_STREAM_TEXT` blindly patched the last DM message. Now every stream targets its own placeholder by id; chatService holds a module-level lock against concurrent streams. |

### Frontend UX & performance

- **Stop button** — players can now cancel a runaway DM generation (AbortController; partial text is kept, marked "— generation stopped —"). Input no longer locks during streaming.
- **401 recovery in `authFetch`** — silently refreshes the session once and retries; signs out cleanly on failure. Previously an expired session meant **silent permanent save loss**.
- **Per-token render cost** — chat rows are now `React.memo`ized; previously every SSE token re-ran the 145-line DM text parser on every historical message. GameContext + AuthContext values memoized.
- **Bundle** — main chunk 587KB → 525KB (gzip 171→155KB): 6 cold routes lazy-loaded, d3 umbrella replaced with scoped `d3-selection`/`d3-force`/`d3-drag` (714 → 240 modules).
- **Dead code deleted** — unused `AuthModal.jsx` (492 lines), unused `MobileNav.jsx` (whose CSS never existed), debug logs, no-op ternary, phantom `state.campaignId` prop.
- **"Chris" is gone** — wizard player name now derives from the signed-in account.
- **maxLength on every input backed by a VARCHAR** — email 255, username 100, password 128, world name 255, character name 150. (A 300-char world name previously 500'd on Postgres while passing on SQLite.)

### Mobile fixes (from the static audit)

- **`viewport-fit=cover`** added — all `env(safe-area-inset-*)` rules were literally no-ops before this.
- **`100dvh`** on root/body/wizard/notification-dropdown — the chat input no longer hides behind mobile Safari's toolbar.
- **Safe-area padding** on the hub bottom nav (home-indicator collision).
- **Touch targets to 44px** — panel icons (36→44), notification Accept/Decline (30→44), mobile panel ✕/← , campaign-picker ✕, hub top-bar bell/back, auth footer links.
- **16px inputs** on archive/invite/profile/feedback fields (iOS zoom trap; root font is 14px so even `1rem` failed).
- **Header stat row hidden on mobile** — it was ~700px of `nowrap` content, clipping Level/HP/Gold off-screen entirely.
- **StatusBar tap now opens the character sheet on mobile** (was a silent no-op — the most inviting target on the screen did nothing).
- **PWA unbroken** — `icon-192.png`/`icon-512.png` now exist (manifest referenced missing files, so installation failed).
- Long unbroken strings wrap in chat bubbles; scroll-pill is a real button.

## Part 2 — The V2 program

### Phase 0 — Foundations (do before any feature work)

1. **Alembic baseline** (M) — `server/alembic/` is EMPTY; `main.py`'s comment "Alembic handles production" is false. Everything below adds schema; `_safe_migrate`'s silent `except: pass` can't carry a rename, index change, or backfill. Init → autogenerate baseline → `stamp head` in prod → `upgrade head` in Docker CMD.
2. **Sentry + PostHog** (S) — no error tracking, no analytics anywhere. The activation/retention targets in the experience spec are unmeasurable today.
3. **Test suite + CI** (M) — zero tests, no `.github/`. Priority coverage: Stripe webhook idempotency + tier transitions, auth token flow (incl. new `tv` revocation), campaign ownership checks. pytest + httpx against SQLite (the seam already exists). One Actions workflow: ruff, eslint, pytest, `npm run build`.

### Phase 1 — Growth surface (weeks 1-2)

4. **SEO story pages** (S) — the server has everything (slugs, excerpts, likes, a public share route); Google sees a blank SPA shell. Bot-detect in `spa_fallback` (or SSR just `/share/{slug}` + `/stories/{slug}`) with og: tags + JSON-LD Article + `/sitemap.xml`. Every finished campaign becomes a permanent acquisition page.
5. **Service worker** (S) — icons fixed today; add `vite-plugin-pwa` for installability + offline shell. Unlocks push notifications later.
6. **Experience-spec P0s** — starter worlds, guest mode, magic link (see 2026-04-20-next-level-experience-design.md — still the product vision).

### Phase 2 — Make premium mean something (weeks 3-6)

7. **The critical revenue finding: `Subscription.tier` gates NOTHING server-side.** Grep confirms tier logic exists only inside billing.py itself. And the product is BYO-API-key — the #1 conversion wall.
8. **Platform-billed inference** (M) — platform OpenRouter key; free tier gets N turns/day on a cheap model, premium gets more + better models. Needs: `UsageLedger` table, `require_within_quota` dependency on chat/images, **server-side model allowlist** (today the client can request any model string), usage-frame parsing in `openrouter.py` (currently discarded), context truncation via the existing summarizer (full history is sent every turn).
9. **Image packs** (M) — xAI URLs currently expire and nothing persists them. R2/S3 upload + `GeneratedImage` table + Stripe one-time credits.
10. **Party Pass** (S/M) — multiplayer inference runs on the HOST's key today. Free = 2 players; pass/premium = up to 6 platform-billed. Enforce at invite-accept.

### Phase 3 — Multiplayer & platform correctness (weeks 6-10)

11. **Socket.IO scale bugs** (M) — in-memory presence dict splits-brain at 2 replicas (→ AsyncRedisManager); `player_action` holds a DB session across the whole LLM stream (same pool-exhaustion bug fixed in HTTP chat today — the socket path still has it); whole-blob `chat_history` read-modify-write loses turns when two players act simultaneously.
12. **Messages table** (M) — kill the `chat_history` JSON blob. Fixes multiplayer lost-updates, unbounded growth, client-authoritative saves.
13. **Server-side DM engine** (M/L) — prompt assembly + tag parsing live in the React client; `/dm-engine.md` serves your entire prompt IP publicly. Extract `services/dm_engine.py` with a `run_turn()` seam. This is the prerequisite for the Discord bot, public API, and correct multiplayer.
14. **Redis + background jobs** (M) — arq for recap/summarizer off the request path, digest emails, distributed rate limiting, Socket.IO manager.

### Phase 4 — Distribution (quarter 2)

15. **Discord bot** (M once #13 lands) — a thin discord.py adapter over `run_turn()`.
16. **Capacitor iOS/Android** (M) — client verified compatible; prerequisite is centralizing the scattered `fetch()` calls behind one API module with a configurable base URL (`useAPI` is currently an unimplemented placeholder).
17. **Public character-sheet API** (S/M) — PAT tokens over the existing `character_data` JSON.

### UX debt backlog (from the desktop audit — schedule into any sprint)

- **Save/sync status indicator** in StatusBar (failures currently invisible; `useCloudSync` fixes today make saves reliable, but users still can't SEE state)
- **Shared `<Modal>`** with Escape/focus-trap/focus-return — AuthModal had the gold standard (now deleted as dead code); Wizard, Archive, Picker, ProfileDrawer all lack it
- **Chat error recovery** — error row + Retry instead of overwriting the DM bubble
- **Surface silent failures**: story like, profile save, friend accept/decline, settings save
- **Archive undo** — "Archive Forever" is irreversible; the `status` enum already supports reversal
- **Fix or remove lying controls**: particle/notification toggles (not wired), theme cards (no onClick), NavRail campaign list (hardcoded `[]`), dead Save & Quit modal in Header
- **Keyboard shortcuts** — zero exist; number-key panel switching + `/` to focus chat first
- **Consolidate 38 button classes** into one variant system
- **Copy fixes**: "Claude generates" → "your AI Dungeon Master", "OOC" unexpanded, "localStorage" shown to players, hub called 3 different names
- **Wizard discard guard** — ✕ silently destroys 5 steps of world-building
- **Split oversized files**: LandingPage 759, AdminPage 507 (+74 inline styles), GameContext 432, CampaignWizard 423
